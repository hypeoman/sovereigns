# Что нужно для проекта и как всё настроить

## Что установить

| Что | Зачем |
| --- | --- |
| **JDK 21** (например, Eclipse Temurin 21) | Minecraft 1.21.1 и NeoForge требуют Java 21 |
| **Git** | история изменений; Claude Code работает с репозиторием |
| **Claude Code** | пишет код, собирает, читает логи игры |
| **CurseForge App** или **Prism Launcher** | экземпляры сборки State of War |
| Аккаунт **GitHub** (желательно) | резервная копия кода, позже — публикация мода |
| IntelliJ IDEA Community (по желанию) | если захочешь сам смотреть код или отлаживать |

Железо: сборка на 177 модов + среда разработки одновременно — рассчитывай на 16 ГБ ОЗУ минимум,
лучше 32.

## Два экземпляра сборки

Сделай **две копии** State of War в лаунчере:

- **State of War — dev**: сюда Claude Code кладёт свежие сборки мода, здесь тестовые миры `sv-test-*`.
  Мод в ней может быть сломан — это нормально.
- **State of War — play**: настоящее прохождение. Сюда мод попадает только когда ты сам
  копируешь проверенную версию.

Обе копии — одной версии сборки. **Отключи автообновление сборки** в лаунчере для обеих:
мод компилируется против конкретных версий модов, и обновление сборки может его сломать.
Если всё же обновляешь сборку — сначала dev-копию, потом пересборка и проверка, потом play.

В CurseForge копию делают через «…» → «Duplicate» на экземпляре (или экспорт/импорт профиля);
в Prism — правый клик → «Copy Instance».

## Репозиторий

1. Создай пустую папку проекта, например `~/projects/sovereigns`, и сделай `git init`
   (или создай пустой репозиторий на GitHub и склонируй).
2. Положи в неё `CLAUDE.md` и папку `docs/` с файлами `ROADMAP.md`, `SETUP.md`.
3. Экспортируй документ с механиками из Claude как Markdown и положи как `docs/DESIGN.md`.

## Связать проект со сборкой

В файле `~/.gradle/gradle.properties` (на Windows: `C:\Users\<имя>\.gradle\gradle.properties`)
добавь путь к **dev**-копии — это папка, внутри которой лежат `mods/`, `saves/`, `logs/`:

```properties
sovereigns.instanceDir=C:/Users/<имя>/curseforge/minecraft/Instances/State of War - dev
```

Путь — свой: в CurseForge он открывается через «…» → «Open Folder» на экземпляре,
в Prism — «Folder». Используй прямые слэши `/`.

Этот файл не попадает в репозиторий — пути у каждого свои.

## Первая сессия Claude Code

Открой терминал в папке проекта, запусти `claude` и напиши, например:

> Прочитай CLAUDE.md и docs/. Начинаем с этапа −1 из ROADMAP.md: создай скелет мода
> и настрой сборку против модов из моего экземпляра. В конце дай мне чек-лист проверки.

Дальше цикл такой: Claude Code делает этап → собирает → `deployToInstance` → ты запускаешь
**dev**-экземпляр, проходишь чек-лист → пишешь, что получилось → Claude Code сам читает логи и чинит.

## Резервные копии

- Код — в git; пушь на GitHub после каждого этапа.
- Тестовые миры не жалко. Миры **play**-экземпляра бэкапь перед каждым обновлением мода:
  данные государств хранятся в сохранении, и ошибка в новой версии может их испортить.
